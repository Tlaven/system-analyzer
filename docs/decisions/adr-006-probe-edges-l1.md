# ADR-006: 双层边(探测边)L1——声明之外,把"运行时事实"也画出来

## 状态

accepted;L1 已实现(2026-09-15);L2(Proxy 化)deferred(远期,需独立 ADR)

## 背景

支柱图"运行时事实"方向:声明边(`attrs.edges`,sourceCode 作者意图)只覆盖**显式**关系;attrs 字段里还藏着**隐式引用**——方法体运行时赋的、bootstrap 里手写的、transform 写进去的。用户和 AI 都无法从画布看出"谁悄悄引用了谁"。

B-L1 目标:从 attrs 引用**推而得之**的探测边,与声明边同屏分层(实线 = 意图,虚线 = 事实)。约束沿用既有原则:演化层不序列化(ADR-005)、防溢出(探测边不抢戏)、零转换(无 deploy 步骤,观测对象就是眼前对象)。

## 考虑过的方案

### 方案 1:L2 直接 Proxy 化 attrs(赋值即图变)(缓期,非本期)

- 优点:无缝 live,写入即刻成边
- 缺点:破坏 attrs 对象恒等(`edges[i].target` 靠 `===` 识别),需要 memoization 表,伤及 JSON round-trip 与双身份系统地基
- **拒绝理由**:抽水太多;先做 L1(派生),语义确认后再评估 L2

### 方案 2:每条 field-path / 每次引用各画一条探测边(被拒)

- 缺点:`A.pool = [B, B, C]` 画 3 条 A→B 平行虚线,背景信息变成噪声,与渲染层"空间分离 > 视觉编码"哲学冲突
- **拒绝理由**:探测边是背景事实,不该抢声明边的戏

### 方案 3:命中实例后继续穿透遍历(被拒)

- 缺点:遍历 B 的 attrs 会把 B 自己的引用传染给 A(A→B→C),探测图退化成可达性图,信息失真
- **拒绝理由**:探测边的语义是"直接引用",不是"可达"

### 方案 4:把 `attrs.edges[].target` 也算进探测边(被拒)

- 缺点:声明边已是一等公民,再派生一遍只是重复
- **拒绝理由**:跳过 `edges` 键后,"探测 − 声明 = 未声明的隐式依赖"语义最干净,差集最有价值

### 方案 5:引用值继续 JSON 化序列化(被拒)

- 现状:`formatValue(object)` 走 `JSON.stringify`,而 `makeBridge` 返回的 attrs 引用是对象
- 缺点:panel 一编辑 → `syncCodeFromRuntime` 把引用**静默**序列化成副本(如 `Node_1.ref = {"y":0}`),重载后引用身份与探测边一起消失——静默语义丢失
- **拒绝理由**:sourceCode 是唯一真相源,引用必须能跨 session;改为递归序列化引用为 varName(环/超深降级 null)

### 方案 6:同对收敛 + 实例边界(采纳)

- 同对多引用收敛为一条,`fields` 记全部 field-path,标签显示首路径 + `×N`
- 只认实例边界:遍历 plain object/array(限深 4 + visited 防环),命中带 `__instId` 的对象即记一条并停止深入
- 跳过 `edges` 键与 `__` 前缀;自引用不记(L1 不渲染自环探测边)

## 选择

选方案 6。探测边纯派生、不序列化、不入 URL hash;lazy 缓存(模式同 `deriveEdges`),失效点:`runSource` / `invalidateEdges`(结构变更聚合)/ `evalTransforms` / `stepAll`(方法体可能改引用)。渲染:灰虚线 + 小箭头 + field-path 标签(仅 medium/full),同对已有声明边则不画(差集口径)。

## 后果

### 正面后果

- 画布对"谁影响谁"多一轨答案:声明实线(意图)/ 探测虚线(事实),未声明隐式依赖可见
- 引用值可持久化:attrs 里写 `Node_1.ref = Hub_1`、容器内嵌套引用,都能完好 round-trip,探测边跨 session 存活

### 负面后果

- 失效点分散(任何改引用的入口都要失效),漏一处就显示过期数据;当前靠"结构变更聚合到 `invalidateEdges` + 引擎两入口"收敛,新入口须自觉接入
- `stepAll` 每 tick 失效 → 连播时逐帧重算探测边(`O(总 attrs)`,小图无感,大图需性能预算)
- `formatValue` 从 `JSON.stringify` 改为递归字面量,行为面扩大(容器环/超深降级 `null`)

### 需要跟进的

- L2(Proxy 化,真·赋值即图变)远期评估——需独立 ADR
- 探测边 hover tooltip(展示全部 field-path)与命中测试暂未做,标签只显示首路径 + `×N`
- 大图性能预算(与 ADR-005 执行观测同题,Web Worker 化一并再议)
